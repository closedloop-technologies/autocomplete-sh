## Agent skills

### Issue tracker

Issues live as markdown files under `.scratch/<feature>/`. When a skill says "publish to the issue tracker" or "fetch the relevant ticket" → read `docs/agents/issue-tracker.md`.

### Triage labels

Five roles, label equal to role name: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. When applying a triage role as a label → map it in `docs/agents/triage-labels.md`.

### Domain docs

single-context: one root `CONTEXT.md` + `docs/adr/`. Before exploring domain terms or decisions → read `docs/agents/domain.md`.
